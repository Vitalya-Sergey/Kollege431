# Система просмотра видео колледжей

Система для просмотра и управления видео, загруженными учебными заведениями.

## Требования

- PHP 7.4 или выше
- MySQL 5.7 или выше
- Веб-сервер (Apache/Nginx)
- Composer (для управления зависимостями)

## Установка

1. Клонируйте репозиторий:
```bash
git clone [url-репозитория]
cd [название-папки]
```

2. Создайте базу данных:
```bash
mysql -u root -p
CREATE DATABASE kollege;
exit;
```

3. Импортируйте структуру базы данных:
```bash
mysql -u root -p kollege < database.sql
```

4. Настройте подключение к базе данных:
Откройте файл `config/database.php` и укажите правильные параметры подключения:
```php
define('DB_HOST', 'localhost');
define('DB_USER', 'ваш_пользователь');
define('DB_PASS', 'ваш_пароль');
define('DB_NAME', 'kollege');
```

5. Создайте папку для загрузки видео:
```bash
mkdir uploads
chmod 777 uploads
```
